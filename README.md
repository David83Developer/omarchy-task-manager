## 🎯 How to Use It

### Find a Specific App

1. Look at the list of running applications in the main window.
2. Use the search box at the top to type part of the app's name (for example, "browser" or "game").
3. The list will filter as you type, showing only matching programs.

### Check Memory Usage

Each row shows the app's name and how much memory (RAM) it's using. This helps you spot programs that are hogging resources — they'll show high numbers like 2 GB or more.

### Close a Frozen or Unwanted App

1. Click the app you want to close to highlight it.
2. Click the "End Task" button (or press the Delete key on your keyboard).
3. Confirm if asked — the app will close immediately.

### Keyboard Shortcuts for Power Users

- **Ctrl + F**: Jump to the search box
- **Delete**: Close the selected app
- **F5**: Refresh the list
- **Esc**: Clear search or close the app
